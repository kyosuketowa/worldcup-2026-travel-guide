# 画像URL集（CC ライセンス・パブリックドメイン中心）

しおりに埋め込む画像のURL集です。すべて自由利用可能（CC ライセンス・パブリックドメイン）か、検索の起点となるURLです。

## 取得方法

```html
<img src="URL" alt="説明" style="max-width: 100%;">
```

または、ローカル保存して `images/` フォルダに整理してください。

## 推奨配置例

### しおりトップ
- 自由の女神（NYパート）
- AT&Tスタジアム（ダラス・W杯パート）
- 日本国旗 + オランダ国旗（試合カード）

### 各スポットカード
- スポットの代表画像を1枚（横長推奨・aspect-ratio 16:9等）
- alt属性に説明を入れる

### W杯セクション
- スタジアム外観
- 日本代表のCC画像（集合写真等）
- 試合カード風デザイン（国旗 + チーム名 + 日時）

### バナー・装飾
- Twemoji の絵文字アイコンで軽く装飾
- マンハッタンのスカイライン（ヘッダー）
- テキサスのアイコン（ダラスセクション）

## ⚠️ 著作権の注意事項（個人使用でも）

- **試合中のプロ撮影写真**は基本NG（Getty Images等の報道機関が著作権保有）
- **報道機関のサイトから保存した画像**もNG
- **JFAの公式選手プロフィール写真**もJFA著作権あり（ただし個人しおりへの埋込は実害なし）
- **公式ロゴ・エンブレム**は商標。個人しおりでの「装飾」レベルなら問題ないが、商用利用や改変は不可

**安全第一の原則**:
1. Wikimedia Commons の CC ライセンス画像を最優先
2. 次に Pixabay / Unsplash の CC0 画像
3. 公式サイトの画像は「しおりへの装飾」レベルに留める
4. 個人で撮った過去の写真があれば最強
